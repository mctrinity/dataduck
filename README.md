# DataDuck

**Get your data in a row.**

## Overview

DataDuck is a cloud-native data quality platform that helps users
profile, cleanse, validate, deduplicate and transform datasets.

## Core Features

- Dataset upload and preview
- Data profiling and quality assessment
- Configurable cleansing rules
- Data standardization and normalization
- Exact and fuzzy deduplication
- Custom dictionaries and exclusion lists
- Before-and-after quality reports
- Cleansed dataset export
- Asynchronous batch processing
